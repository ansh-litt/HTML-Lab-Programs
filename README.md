# HTML Lab Programs

A collection of HTML lab exercises for the Online Book Store (BookNest) practical file.

## Programs included

1. **Program 1 — Basic HTML Tags:** A simple first webpage.
2. **Program 2 — Online Book Store:** A static BookNest storefront with featured books, categories, offers, reviews and contact details.
3. **Program 3 — Login Page:** A login form for BookNest.
4. **Program 4 — Book Catalog:** A table showing book name, author, domain, publisher and price.
5. **Program 5 — Shopping Cart:** A cart table with book details and total price.
6. **Program 6 — Registration Form:** A form for user details, password, email, phone, language, gender and address.
7. **Program 7 — Customer Request Page:** A form for email ID, contact number, address and customer query.

## How to run

Open any `programN.html` file in a web browser, or open the folder in VS Code and use Live Server.

These are front-end HTML practice exercises. Forms and buttons are demonstrations; they do not submit data to a server or perform real purchases.

## Adding Program 8 later

When Program 8 is ready, add `program8.html` to this folder and update this README. Then run:

```bash
git add program8.html README.md
git commit -m "Add HTML Lab Program 8"
git push
```
